# VS Code + язык C: быстрый старт

## 1. Что скачать

| Что | Откуда | Куда |
|---|---|---|
| VS Code | code.visualstudio.com | обычная установка |
| Компилятор w64devkit | github.com/skeeto/w64devkit/releases → файл `w64devkit-*.zip` | распаковать в `C:\Users\<логин>\dev\w64devkit` |

Проверьте, что внутри архива есть `bin\gcc.exe`.

## 2. Прописать PATH

`Win+R` → `sysdm.cpl` → вкладка «Дополнительно» → «Переменные среды» → в **верхнем** блоке («Переменные среды пользователя») выберите `Path` → «Изменить» → «Создать» и вставьте:

```
C:\Users\<логин>\dev\w64devkit\bin
```

ОК во всех окнах. Затем **полностью закройте и заново откройте VS Code**.

Проверка: откройте терминал в VS Code (`Ctrl` + `` ` ``) и введите

```
gcc --version
```

Вывелась версия — готово.

## 3. Расширение

`Ctrl+Shift+X` → найдите **C/C++** (автор Microsoft) → Install.

## 4. Папка проекта

`File → Open Folder` → выберите **папку**, например `C:\Users\<логин>\dev\c`.

> ⚠️ Открывать нужно папку, а не отдельный файл. Иначе расширение C/C++ не работает.

Создайте внутри файл `hello.c`:

```c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

## 5. Сборка и запуск

В терминале VS Code (`Ctrl` + `` ` ``):

```
gcc -g hello.c -o hello.exe
.\hello.exe
```

- `gcc ... -o hello.exe` — собрать программу
- `.\hello.exe` — запустить её
- `-g` — добавить отладочную информацию (нужна для F5)

На экране должно появиться `Hello, world!`

## 6. Если не работает

| Симптом | Что делать |
|---|---|
| `gcc не является внутренней или внешней командой` | PATH прописан неверно, либо VS Code не перезапущен |
| Русский текст в консоли — кракозябры | выполните `chcp 65001` перед запуском |
| Собралось, но работает по-старому | **вы не сохранили файл.** `Ctrl+S` |
| F5 ничего не запускает | собрано без `-g` |

## 7. Горячие клавиши

- `Ctrl` + `` ` `` — открыть/закрыть терминал
- `Ctrl+S` — сохранить файл
- `Ctrl+Shift+P` — все команды VS Code
- `F5` — запуск с отладкой
- `F9` — поставить/снять точку останова
